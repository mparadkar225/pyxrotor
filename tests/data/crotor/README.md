# CROTOR sample rotors

`cr1.xr` and `cr2.xr` are `esotec/crotor/CR1.xrotor` and `CR2.xrotor` from CROTOR
755-ES1.3 (Philip Carter, Esotec Developments; GPL v2 or later), copied unchanged from
github.com/mparadkar225/crotor. They are a counter-rotating pair (2 + 2 blades, R = 0.8 m)
designed for 80 kW total at 3000 rpm and 35 m/s; each file carries the slipstream it saw
in the converged CROTOR solution. CROTOR's README: load CR1 as the forward rotor (LFWD),
CR2 as the aft rotor (LAFT), INPU 80000 W, 3000 rpm, 35 m/s, then RPM or POWE.
